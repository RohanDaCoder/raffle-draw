Printing tips

  • Print at 100% scale / Actual size — never “Fit to page”, it shrinks the grid.
  • A4 paper, single-sided; cut along the dashed lines.
  • Keep sheets whole: cut a ticket off only when it sells, tear body from stub, stub goes in the jar immediately.
  • Numbering plan: standard 001–480, VIP pre-orders 481–495. Extra standard tickets should start at 496 so no two stubs share a number.
